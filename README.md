# Life OS Alpha — React/Vite

Mobile-first web app source for testing Life OS on iPhone through Vercel/Netlify.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deploy on Vercel
1. Create a GitHub repo and upload this folder.
2. Go to https://vercel.com/new
3. Import the repo.
4. Framework preset: Vite
5. Build command: npm run build
6. Output directory: dist
7. Deploy.
